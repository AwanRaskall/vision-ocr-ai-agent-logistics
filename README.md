# Vision OCR AI Agent Logistics

AI-powered logistics platform that processes photos of CMR and shipping documents using OCR, Computer Vision and LLMs. Extracted shipment data is then used by an AI agent to find suitable transportation options and automate logistics workflows.

## Tech Stack

- Python 3.12.6
- FastAPI
- Computer Vision / OCR
- Hugging Face
- PyTorch
- LLM
- AI Agent
- React
- JavaScript
- HTML / CSS
- LangChain
- LangGraph
